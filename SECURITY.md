# Security policy

## Supported versions

AIAuditLog is Beta software. Security fixes are applied to the latest release only.
Upgrade with `pip install -U aiauditlog`.

## Published advisories

No security advisories have been published for `aiauditlog`.

All advisories: [github.com/sekacorn/AIAuditLog/security/advisories](https://github.com/sekacorn/AIAuditLog/security/advisories).

## Reporting a vulnerability

Please do not report a suspected vulnerability in a public issue.

Report a suspected vulnerability privately with **Report a vulnerability** on the repository's
[Security tab](https://github.com/sekacorn/AIAuditLog/security) (direct link: [github.com/sekacorn/AIAuditLog/security/advisories/new](https://github.com/sekacorn/AIAuditLog/security/advisories/new)).
This is GitHub's private vulnerability reporting: the report stays private between you and the
maintainers until an advisory is published.

Include the affected version, reproduction steps and the impact you observed.
Never include real credentials or private data.
